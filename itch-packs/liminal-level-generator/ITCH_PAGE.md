# Liminal Level Generator — Godot 4

**Endless school corridors, empty halls and bottomless pools. One function call.**

The level system behind the liminal horror game *Neon Exile*, as a clean drop-in.

### Features
- 🏫 **3 styles**: corridor with classrooms ("rooms"), halls with dead ends, pool rooms with bottomless pits
- 🚪 **Swing doors** that open when the player (or NPCs) get close, connecting doors between rooms
- 🪟 **Windows** with glass looking out onto a yard with trees and open sky
- 🕳️ **Bottomless pools** with narrow walkways + a `fell_into_pit` signal
- 🪑 Classroom **furniture** (board, desks, chairs) and a list of free seats for seated NPCs
- ➡️ Subtle **floor arrows** that guide the player along the main path
- 🔵 **Rounded corners** – no more boxy grid look
- Seeds, text layouts you can edit by hand, guaranteed connected path start → exit
- Fast: merged geometry, MultiMesh corners. Godot **4.3+**, all renderers, pure GDScript.
