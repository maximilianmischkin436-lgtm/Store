# Liminal Texture Pack

18 seamless 1024×1024 textures for liminal spaces – the surfaces of the game *Neon Exile*.

Pool_Tiles · Mall_Terrazzo · Mall_Wall_Panels · Office_Carpet · Office_Wallpaper · Dark_Oak_Paneling · Green_Library_Carpet · School_Checker_Floor · School_Wall_Tiles · Hospital_Linoleum · Hospital_Wall_Tiles · Worn_Wood_Floor · Old_Home_Wallpaper · Faded_Floral_Wallpaper · Subway_Platform_Concrete · Subway_Station_Tiles · White_Marble_Void · Meadow_Grass

**Format:** PNG, 1024×1024, tileable. See `Preview.png`.

**Godot tip:** use them in a StandardMaterial3D with *UV1 → Triplanar* + *World Triplanar* and `uv1_scale = 1/3` – no UV unwrapping needed for blocky level geometry.
